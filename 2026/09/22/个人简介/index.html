在跑道上追速度，在代码里追智能。

研究方向：人工智能与大语言模型

项目经历

RISC-V 五级流水线 CPU

计算机组成原理课程实验。用 Verilog 在 Vivado 上从零搭出一个 RISC-V 五级流水线 CPU，并逐层解决流水线带来的问题：

  • 实现写优先寄存器堆和统一的段间寄存器，处理数据冒险与控制冒险
  • 加入前递（forwarding）模块和段间寄存器控制模块，减少流水线停顿
  • 设计二路组相连 Cache，分别实现 LRU、随机、FIFO 三种替换策略，并扩展到 N 路组相连；通过仿真对比运行时间，验证 LRU 表现最好（27.116 μs）

NexOS 操作系统内核

操作系统课程实验。基于教学用的类 Unix 内核 NexOS，在三个方向上动手：

  • 系统调用与 Shell：从一个新系统调用出发，打通用户态到内核态的完整链路，理清用户态参数与系统调用号分别通过哪些寄存器传递；区分内建命令与外部命令，理解 Shell 如何用 fork + exec 拉起外部程序
  • 虚拟内存：分析 sbrk 扩展与收缩堆时空闲链表的分裂和合并，定位写缺页异常，对比只读页面与写时复制（COW）在 PTE_W 上的差异
  • 文件系统与磁盘调度：梳理打开文件表与索引结点（inode）的结构，推演 FCFS、SSTF、SCAN、LOOK、C-SCAN、C-LOOK 六种磁盘调度算法的寻道过程
